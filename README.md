 ShoeStore – Online Shoe Shopping and Delivery System

 1. Project Overview

ShoeStore is a web-based shoe shopping system developed to simplify the process of browsing shoes, placing orders, managing payments, and handling deliveries. The system provides separate interfaces for administrators, customers, and delivery personnel.

 2. Project Objectives

- Make it easier for customers to browse and order shoes online.
- Help administrators manage products, customers, and orders.
- Enable delivery personnel to manage assigned deliveries.
- Support efficient order tracking and delivery management.
- Provide a convenient online shopping experience.

 3. Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js and Express.js
- **Database:** MySQL
- **Version Control:** Git and GitHub

 4. Main Features

 Administrator
- Secure login and access control
- Manage shoes and product information
- Manage customer accounts and orders
- Manage delivery personnel
- Monitor system activities

 Customer
- Register and log in
- Browse available shoes
- Place and manage orders
- Choose available payment methods
- View order and delivery information

 Delivery Personnel
- Log in to a delivery account
- View assigned deliveries
- Update delivery status
- Track delivery activities
- View delivery earnings

 5. Installation and Setup

 Prerequisites
- Node.js and npm
- MySQL Server
- Git

 Steps
1. Clone this repository:

   bash
   git clone https://github.com/Alice DUSABIMANA/ShoeStore.git
   

2. Enter the project directory:

   bash
   cd ShoeStore
   

3. Install the project dependencies:

   bash
   npm install
   

4. Configure the database connection using environment variables in a local `.env` file.

5. Create and configure the MySQL database using the project's database schema or SQL setup files.

6. Start the application using the appropriate command defined in `package.json`.

**Note:** Installation commands may need to be adjusted if the frontend and backend have separate `package.json` files.
